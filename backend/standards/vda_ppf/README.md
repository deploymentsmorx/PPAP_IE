# VDA PPF/PPA

Scaffold for VDA Volume 2 production process and product approval support.

This folder contains the first VDA-specific assets:

- `tagging/elements.json`: 19 VDA PPF/PPA artifact definitions.
- `tagging/keywords.json`: VDA-specific tagging vocabulary.
- `validation/checkpoints/vda_validation_checkpoints.json`: prompt-ready VDA
  validation catalog with evidence-bound rules.

The detailed VDA Band 2 text is copyrighted. The checkpoint catalog uses
original project language based on public PPF/PPA artifact knowledge and should
be reviewed against a licensed VDA source before being treated as a formal
compliance checklist.
